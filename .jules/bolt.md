## 2026-10-11 - Optimize unbounded logging/history structures with collections.deque
**Learning:** In Python, maintaining a bounded history or ring buffer using `list.pop(0)` creates an O(N) performance bottleneck as it shifts all elements upon every eviction. This becomes particularly costly in hot paths like logging or metric collection.
**Action:** Use `collections.deque(maxlen=...)` instead for automatic O(1) eviction when a length limit is reached. Note that since `deque` is not directly JSON-serializable, ensure that functions returning these collections cast them back to a standard `list` (e.g., `list(self._logs)`) to maintain interface compatibility.
